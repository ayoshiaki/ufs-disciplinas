# Código da aula --- Fundamentos de React Native e primeiras telas

Todos os arquivos são `App.js` de um projeto **Snack** (https://snack.expo.dev).
Nada precisa ser instalado: abra o Snack no navegador, apague o conteúdo do
`App.js` que vem pronto, cole o arquivo desejado e leia o QR code com o
**Expo Go** no celular.

| Diretório | Quando usar na aula | O que introduz |
|---|---|---|
| `01-ola-mundo/` | Bloco 3 --- primeira tela no celular | `View`, `Text`, `StyleSheet`, `flex: 1` |
| `02-componentes-e-estilo/` | Bloco 4 --- catálogo de componentes | `Image`, `TextInput`, `Pressable`, `flexDirection` |
| `03-contador/` | Bloco 5 --- estado | `useState`, atualizador funcional |
| `04-campo-controlado/` | Bloco 5 --- estado | `value` + `onChangeText` |
| `cartao-perfil/esqueleto/` | Atividade dos alunos | ponto de partida com os `TODO` |
| `cartao-perfil/checkpoint-1/` | Gabarito parcial | layout, Flexbox e `map` |
| `cartao-perfil/checkpoint-2/` | Gabarito parcial | contador de curtidas |
| `cartao-perfil/checkpoint-3/` | Gabarito parcial | bio como campo controlado |
| `cartao-perfil/checkpoint-4/` | Gabarito final | botão Seguir/Seguindo e valor derivado |

**Aviso ao projetar a aula:** publique os checkpoints só depois que a turma
tentar cada etapa. O esqueleto é o único arquivo que os alunos recebem no começo.
